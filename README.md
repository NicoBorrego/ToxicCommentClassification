# ToxicCommentClassification

## What is about?

This repo is focused on learning how to develop, optimize and evaluate a supervised machine learning model to treat Natural Language Processing and classify a toxic or non-toxic comment provided by the user.

Once the model is selected, lets proceed with an external validation with [Youtube Comments Dataset](https://www.kaggle.com/datasets/mehtaakshat/youtube-comments-data-sentiment-toxicity-spam) from Kaggle.

Also, you can try the model on my own [portfolio](https://bold-block-32cb.nicolasborregogonzalez.workers.dev/)

## Selected model

After trying some classification model as logistic regresion, random forests, etc. I decided to use LinearSVC from SVM as explained on the repo Notebook.
